Web-based Centralized Faculty Evaluation System

Admin: bcevaluation.vercel.app/admin
User: bcevaluation.vercel.app

The Web-based Centralized Faculty Evaluation System is designed to improve the faculty evaluation process by providing a centralized platform for collecting, managing, and organizing evaluation records. The system aims to reduce manual processing, improve accessibility of evaluation results, and make report generation more efficient.

The proposed system provides a centralized platform for conducting faculty evaluations, managing records, monitoring submissions, and generating reports. It supports three main user roles: Admin, School Head/Principal, and Student.

Main Features

-User authentication and role-based access
-Faculty and user management
-Online faculty evaluation
-Centralized evaluation records
-Evaluation history and reports
-Evaluation monitoring
-Report generation and export
-Dashboard statistics
-Technology Stack

Frontend: Next.js, React, TypeScript, Vite, Tailwind CSS
Backend: Node.js, Express.js, REST API
Database: MySQL
Tools: Visual Studio Code, EchoAPI, GitHub
Deployment: Vercel and Railway

Project Status

-Currently in development and documentation stage. The system and its features are still being developed and refined.
