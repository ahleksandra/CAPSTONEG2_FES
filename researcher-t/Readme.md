### 3. Conceptual Framework
The study follows the *Input–Process–Output (IPO) Model*.

#### Input
Includes the resources and requirements needed for the study:
- Existing faculty evaluation process
- Research references
- User requirements
- Software and hardware requirements

#### Process
Describes the development stages:
- Planning
- Requirements gathering
- System analysis
- System design
- Development
- Testing
- Implementation
- Evaluation

#### Output
The expected result of the study:
- A Web-based Centralized Faculty Evaluation System
- Improved faculty evaluation process
- Centralized database
- Automated report generation
- Efficient data management
